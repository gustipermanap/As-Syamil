# 11 — Istilah baku

Pakai kolom “Pakai ini” di UI. Jangan pakai kolom “Jangan”.

| Pakai ini | Jangan | Arti |
|---|---|---|
| Santri | Siswa | Peserta didik pesantren |
| Wali santri | Orang tua siswa | Penanggung jawab santri |
| Ustadz / ustadzah | Guru | Pengajar |
| Musyrif / musyrifah | Pembina asrama | Pengurus asrama |
| Pengasuh / mudir | Kepala sekolah (kecuali unit formal butuh label tambahan) | Pimpinan pesantren |
| Tata usaha | Admin (sebagai nama peran) | Staf administrasi |
| Bendahara | Kasir saja | Pengelola keuangan jika dipilih |
| Syahriyah | SPP | Iuran berkala |
| Halaqah | Kelas (jika yang dimaksud lingkaran kitab) | Kelompok kajian |
| Rombongan belajar (RB) | — | Wadah santri + pengampu dalam satu tahun ajaran |
| Kitab | — | Bahan ajar diniyah |
| Setoran | PR / kuis | Penyimakan hafalan |
| Ziyadah | — | Hafalan baru |
| Muroja’ah | — | Mengulang hafalan |
| Tasmi’ | — | Setoran utuh (biasanya per juz) |
| Kamar / asrama | Asrama siswa | Hunian |
| Izin pulang | Cuti | Izin meninggalkan pondok |
| Gelombang PPDB | Tahun ajaran (sebagai pengganti PPDB) | Periode penerimaan |
| Nomor induk santri (NIS) | NIP | Nomor internal santri |
